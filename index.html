GitHub Pages に index.html 1つだけ置けば動く構成です。上部に市場の動き、中央に大きなチャート、下部に地域別カード型チャートを並べています。

構成単一 HTML
データ取得外部ウィジェット
必要設定API キー不要

使い方

下のボタンを押すと、大きなチャートの表示対象が切り替わります。下段のカードには各地域の代表ETFを並べているので、数字だけでなく形でも動きが見えます。

必要なら銘柄コードを差し替えて、日本株中心版や指数中心版にも簡単に変更できます。

メインチャート

主要地域・指数・為替の代表銘柄を切り替えて表示します。

地域別チャート一覧

各カードに簡易チャートと価格情報を表示します。

設置方法: このファイルを index.html という名前で、GitHub の home リポジトリ最上位に置き換えてコミットしてください。
補足: 下段のカードは「各地域の代表ETF」を使っています。あとから指数や個別銘柄へ差し替え可能です。
表示されない場合: 企業ネットワークやブラウザ拡張機能が外部スクリプトをブロックしていないか確認してください。
